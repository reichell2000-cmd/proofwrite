# ProofMe 무료 핵심 기능 · 2026-09-29

기본 목표는 학생이 수행한 과정을 생각·집중·성실·노력·나라는 다섯 증거로 보여주는 것입니다. 유료 개인 코칭, 미리 연동, 장기 성장 분석은 이번 변경에 포함하지 않았습니다.

## 학생 확인 순서

1. 교사의 참여 링크에서 과제에 참여합니다.
2. 과제 안내의 **나의 타자 기준 등록·확인**을 엽니다.
3. 학생 연결을 만들고 비밀 연결 코드를 내려받아 보관합니다. 기존 브라우저의 과제가 본인 것일 때만 연결에 체크합니다.
4. 타자 등록에 동의하고 안내 문장을 따라 칩니다. **타자 기준 등록하기**를 눌러 **타자 기준 등록 완료** 표시를 확인합니다. 입력만으로 자동 등록되지 않으며 자유 입력 단계는 없습니다. 문장이 일치하고 같은 입력 방식의 유효 간격이 80개 이상이면 등록할 수 있습니다. 최소 분량은 시범 설정이며 인증 정확도를 보장하는 수치가 아닙니다.
5. 과제로 돌아가 작성 화면의 **타이핑 습관 비교에 참여**를 선택합니다. 같은 기기의 등록 기준만 사용하며 일반 입력과 한글 조합 입력은 따로 비교합니다.
6. 자료를 첨부하고 맨 아래에서 제출합니다. 노력의 증거는 교사가 평가에 포함한 경우 필요합니다.
7. **나의 증명 보고서**를 열고 인쇄·브라우저 PDF 저장을 이용합니다. 작성 기록에 대한 설명·재확인 요청은 제출 원문과 별도로 남깁니다.

등록은 선택 사항이며 등록하지 않아도 제출할 수 있습니다. 다른 앱의 입력을 수집하지 않습니다. 음성 입력 등 비교 표본이 없는 방식은 자료 부족으로 표시합니다.

## 교사 확인 순서

1. 유형·대상 학년·중요하게 볼 기준을 정합니다. 초등 1~4학년은 간단한 세 부분 양식을 제공합니다. 권장 학년은 제품 사용 가이드이며 공식 교육과정 인증이 아닙니다.
2. 추천 배점을 미리 보고 적용합니다. 교사 직접 항목·제외·고정 배점은 보존합니다. 목표 문장에 들어간 단어만으로 배점을 바꾸지 않습니다. 피드백 방식으로 바꿨다가 돌아와도 이전 배점은 유지됩니다.
3. 학생의 등록 모습을 직접 본 경우에만 **다섯 가지 증거 → 학생의 타자 기준 확인**에 표시합니다. 같은 이름이라는 이유만으로 신원을 확인하지 않습니다.
4. 원문과 추천 대목을 읽고 점수·근거·피드백을 확정합니다. 자료가 부족한 증거는 0점 대신 사유와 함께 계산에서 제외합니다. 남은 만점과 100점 환산을 학생에게 공개하며 모든 항목이 자료 부족이면 확정하지 않습니다.
5. 과제 자료와 노력 자료, 제출 후 재확인 요청을 구분하여 확인합니다.

## 타자 기준의 의미와 관리

학생 연결 코드는 192비트 무작위 비밀값을 포함하며 서버에는 해시만 저장합니다. 코드 재발급은 기존 코드와 이전 세션을 해제합니다. 같은 이름을 새로 등록해도 다른 학생의 문서는 볼 수 없습니다. 코드와 로그인된 기기를 모두 잃으면 이름만으로 복구하지 않습니다.

기기·입력 방식별 기준은 최대 10개입니다. 등록 문장과 원시 표본은 기준 파일에 보관하지 않고 집계값만 저장합니다. 과제 수행의 선택적 원시 시간 표본은 기존 작성 기록에 남습니다. 등록은 서버가 발급한 30분 유효 1회 절차를 사용합니다. 만료·재사용·기기 혼합·부족한 표본을 거절합니다. 한글 문장에 섞이는 공백·문장부호의 일반 입력은 조합 입력 표본과 분리합니다. 브라우저의 사건 자체가 진실함을 보증하는 장치는 아닙니다.

2026-09-30 등록 화면 개선: 자유 입력을 제거하고 따라 치기 집계값을 비교 기준으로 사용합니다. 버튼은 입력 중에도 표시되며 문장 불일치 위치, 남은 글자 수, 등록 전·완료 상태를 안내합니다. 기존 등록 기준은 그대로 읽고 사용하며 자동 교체하지 않습니다. 이전 화면에서 보내는 자유 입력 필드는 저장하지 않고 무시하므로 이미 열린 화면도 저장 요청을 처리할 수 있습니다.

등록 기준 비교는 간격 중앙값 40%·상위 간격 20%·키 누름 시간 25%·연속 입력 15%의 시범 유사도입니다. 관찰 가능한 지표 2개 이상과 유효 표본 80개 이상이 필요합니다. 가중치·최소 표본은 실제 환경에서 보정해야 하며 본인일 확률로 해석하지 않습니다. 연결된 학생에게 기준이 없으면 과제 전후반 비교로 대체하지 않습니다.

재등록은 교사 확인을 승계하지 않습니다. 이후 초안은 새 기준을 쓰고 이미 제출한 문서는 당시 기준을 유지합니다. 기준 삭제 시 같은 기기·입력 방식의 저장 비교 기준도 제거하지만 글·작성 이벤트·확정 교사 평가는 유지합니다.

## 첨부와 운영 범위

PDF는 2MB, 사진은 12MB까지 선택합니다. 큰 사진은 최대 변 1,800px JPEG로 줄여 2MB 이하로 저장하고 가독성 확인을 안내합니다. 일반 과제와 노력 각각 최대 3개입니다. PPT·영상은 외부 제작 후 링크·설명을 남기며 전체 편집기는 포함하지 않습니다.

자동 과정기록 점수와 교사 과제 평가는 구분합니다. 교사 중간 메모는 학생에게 공개하지 않습니다. 보고서는 인증서가 아닌 기록물이며 기존 열람 권한이 필요합니다.

현재 운영 단위는 기존 단일 교사 비밀번호의 Pilot입니다. 다중 교사 권한, 기관 SSO, 자동 원격 백업, 코드 분실 후 관리자 복구는 별도 과제입니다. 기존 영속 볼륨에 students/가 추가되며 기존 과제 배점이나 데이터를 초기화하지 않습니다.

교사용 AI 초안은 `PROOFWRITE_AI_API_KEY`와 `PROOFWRITE_AI_MODEL`을 모두 설정해야 생성됩니다. 현재 전용 설정이 없어 기본 읽기 안내가 작동하며 이를 AI 분석으로 표시하지 않습니다. 다른 서비스의 키를 가져오지 않습니다.
