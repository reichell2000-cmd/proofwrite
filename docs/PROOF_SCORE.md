# Proof Score v0.1 — 교사용 과정기록 종합점수

2026-09-27 후속 개발: 누락됐던 종합점수 요구를 반영해 교사 목록과 증거 탭에 복원했다. 학생 화면에는 숫자를 표시하지 않는다. 글을 열면 전체 본문부터 보이며, 종합점수는 읽기나 구체적인 피드백의 조건을 대신하지 않는다.

## 산정 범위

기존 FREE 기획의 가중치 30/25/20/15/10을 유지한다. 아래 항목은 **자동 작성 기록의 충분성**을 요약하는 계산 요소다. 생각·집중·성실·노력·나라는 증거의 능력 점수를 각각 자동 채점한 것이 아니다. 작성 일정과 학생이 남긴 노력의 의미, 실제 글의 질은 다섯 증거 및 내용 후보를 읽고 교사가 판단한다.

| 계산 요소      | 최대 | 계산식                                                                   |
| -------------- | ---: | ------------------------------------------------------------------------ |
| 작성 흔적      |   30 | min(15, 기록 시점 수×3) + min(10, 입력·삭제 문자/50) + min(5, 세션 수×2) |
| 입력 습관 비교 |   25 | 같은 입력 방식의 간격 유사도×25. 유효 표본 충분할 때만 계산              |
| 입력 기록      |   20 | min(20, 입력·삭제 문자/30)                                               |
| 수정 기록      |   15 | min(10, 수정 횟수×0.7) + min(5, 삭제가 포함된 120자 이상 변경 횟수)      |
| 과정 연결      |   10 | min(5, 기록 시점 수) + min(5, 활동 구간 분 수)                           |

각 요소를 반올림하고 합산한다. 입력·삭제가 전혀 없는 기록은 0이다. 붙여넣기 크기나 창 이탈 자체로 감점하지 않는다. 활동 구간은 편집 사건 사이 60초 이내 간격 추정값이며 실제 집중시간이 아니다. 버전 수·수정량·시간을 기반으로 하므로 짧은 글, 보조 입력, 편집기 밖 사고, 과제 유형에 따른 한계가 있다.

입력 습관 비교가 없으면 해당 없음(null)으로 제외한다. 나머지 합계/75×100을 반올림하고 화면에 분모와 환산식을 표시한다. 리듬이 있으면 합계/100×100이다. 두 범위는 단순 비교할 수 없다. 무한대·NaN도 비교 자료 없음으로 처리한다.

## 리듬 일관성

종합점수와 다섯 증거는 동일한 관찰 함수를 사용한다. 0 초과 5000ms 미만 유효 간격만 사용하고 일반/한글 조합 입력을 섞지 않는다. 현재 표본 최소 80개, 전·후반은 각각 40개 이상 필요하다. 같은 방식의 유효 이전 제출 요약이 있으면 그것과 비교하고, 없으면 과제 전·후반을 비교한다. 옵트아웃 시 남아 있는 과거 표본도 계산에서 제외한다.

유사도 = max(0, 1 − |두 중앙값의 차이|/max(80, 두 중앙값)). 이는 본인 작성 확률이 아니며 기기·피로·입력 방법이 달라지면 차이가 날 수 있다.

## 표시와 해석

80 이상 ‘과정증거 충분’, 55 이상 ‘확인 권장’, 그 아래 ‘과정 확인 필요’. 가중치와 구간은 현장 검증 전 시범 가설이다. 부정행위·AI 활용률·내용 우수성·성적을 자동 판정하지 않는다. 높은 값도 조작 가능하며 낮은 값이 정상일 수도 있다. 학생 순위나 자동 제재 기능은 없다.

교사는 실제 본문 인용·강점과 이유·다음 수정 한 가지를 남긴다. 최소 읽기는 서버에서도 확인하며 학생의 후속 연습은 원문과 점수를 바꾸지 않는다. 학생 데이터의 재작성이나 점수 저장 마이그레이션 없이 서버에서 현재 기록을 계산한다.
