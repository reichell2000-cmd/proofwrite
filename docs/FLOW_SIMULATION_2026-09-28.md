## 기준을 언제 확정하는가

평가 항목과 배점은 과제를 게시할 때 확정한다. 제출 후에는 그 기준에 따른 학생의 점수와 피드백을 확정한다. 과제별 평가표는 학생 참여 시 제출 데이터에도 함께 보관한다. 게시 후 배점·유형을 몰래 바꾸는 경로는 제공하지 않으며, 다른 기준은 새 과제로 안내한다. 마감 변경은 기존 설정에서 가능하다.

기존 과제에는 기존 제출·피드백·과정기록 종합점수를 유지한다. 새 과제의 교사 확정 점수와 이전 시범 과정기록 점수를 혼합하지 않는다. 새 기능 확인은 ‘새 과제’에서 시작한다.

## 점검하며 보완한 부분

1. **노력 제외와 제출 검증의 불일치:** 학생 화면과 서버가 같은 게시 기준을 사용한다. 제외된 노력의 증거 때문에 제출이 막히지 않는다.
2. **첨부와 노력의 혼동:** 일반 과제 첨부를 노력 자료와 분리했다. 노력 평가를 제외해도 PDF·이미지 등 허용된 자료를 제출할 수 있다.
3. **빈 양식 제출:** 기본 제목·표 머리말만 있는 문서는 본문을 쓴 것으로 처리하지 않는다.
4. **자동 배분의 예측 가능성:** 교사가 고정한 배점을 보존하고, 변경 전후를 본 뒤 적용한다. 기준 합계가 100점이 아니면 게시를 막는다.
5. **교사 직접 항목의 누락:** 미입력을 0점으로 처리하지 않는다. 직접 항목과 과정 증거에는 교사의 판단 근거를 요구한다.
6. **점수의 조기 공개:** 중간 저장한 평가와 피드백은 학생에게 공개하지 않는다.
7. **다른 창의 평가 덮어쓰기:** 마지막 평가 저장 시점을 비교하여 오래된 화면의 저장을 거절한다.
8. **확정한 평가의 수정:** 재확정할 때 서버가 총점을 다시 계산한다. 이전 총점이 새 요청에 섞여 저장을 막는 문제를 제거했다.
9. **휴대전화의 좁은 배점표:** 작성 화면의 확정 배점표가 두 열 중 좁은 한쪽에 들어가지 않도록 전체 폭을 사용한다.
10. **AI와 기본 안내의 혼동:** AI 연결 전·응답 실패 시 기본 읽기 안내임을 표시한다. 실제로 생성하지 않은 AI 평가나 점수를 만들지 않는다.

## 실행한 검증

- 단위·서버 검사 **51개 통과**: 기존 35개와 새 평가 기준·8개 양식·배분·직접 평가·AI 응답 검증 16개.
- Chromium 브라우저 시나리오 **7개 통과**: 교사 게시 → 학생 참여 → 유형별 작성 → 첨부·제출 → 읽기·채점 → 평가 공개 → 재확정, 8개 유형 화면, 기존 한글 조합 이벤트·문서 편집·오프라인 복구·다음 학생·학생 다시쓰기.
- 새 통합 시나리오에서는 노력 평가 제외, 고정 배점 10점·교사 직접 항목 20점 보존, 일반 PDF 첨부, 재접속, 미채점 확정 차단, 중간 평가 비공개, 오래된 평가 요청 거절을 확인했다.
- 교사가 확정한 95점이 학생에게 보이고, 직접 항목을 수정·재확정하면 94점으로 갱신되는 것을 확인했다.
- 첫 브라우저 시도에서 과제 유형 선택 요소의 접근성 식별이 맞지 않아 실패했다. 선택 요소의 이름을 명시하고 재시험하여 통과했다.

- TypeScript 검사와 Next.js 운영용 빌드를 통과했다. 휴대전화 배점표 전체 폭 보완 후 새 통합 시나리오를 추가로 재실행하여 통과했다.

## AI 연결 범위와 남은 운영 설정

운영 환경 조회 당시 AI 키와 모델 설정이 없었다. 기본 배점 추천은 유형별 양식과 목표의 창의·근거 표현을 반영하는 규칙 기반이며, AI가 교사의 교육관 전체를 분석한 결과가 아니다.

선택 AI 검토 연결을 구현했다. PROOFWRITE_AI_API_KEY와 PROOFWRITE_AI_MODEL을 설정하면 제출 본문과 허용된 내용 평가 기준을 바탕으로 요약·실제 인용·강점·질문·다음 수정·내용 항목 점수 후보를 요청한다. 본문에 없는 인용, 배점 범위 초과, 교사 직접 항목·과정 증거·즉석 대응 점수는 응답 검증에서 거절한다. AI 초안을 반영해도 읽기 확인이나 교사 최종 동의가 자동으로 완료되지 않는다.

이번 AI 검사는 모의 응답과 실패·미연결 처리를 검사한 것이다. 실제 유료 API 호출이나 실제 학생의 평가 타당성 검증을 수행했다고 주장하지 않는다. 현재 연결 설정이 없으면 교사는 기본 읽기 안내와 직접 평가를 사용한다.

PPT·영상 편집, 복잡한 수식 계산, 외부 제작 과정 관찰, 다중 교사 계정·실시간 모둠 공동 편집은 이번 변경 범위에 포함하지 않는다. 외부 수행은 링크·자료·설명과 교사의 직접 확인으로 연결한다.
