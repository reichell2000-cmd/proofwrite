# Pilot 운영 안내

## 1. 실행 환경

- Node.js 22+, 단일 프로세스/단일 인스턴스, 영속 디스크.
- `.env.local`: `PROOFWRITE_TEACHER_PASSWORD` 12자 이상, `PROOFWRITE_SESSION_SECRET` 서로 다른 난수 32자 이상, `PROOFWRITE_DATA_DIR` 절대 영속 경로.
- 배포 도메인이 정해지면 `PROOFWRITE_PUBLIC_ORIGIN=https://도메인`을 설정합니다. 끝에 `/`를 붙이지 않습니다.
- 개발: `npm ci && npm run dev`. 배포: `npm ci && npm run build && npm start`.
- 교사 로그인 → 과제 만들기 → 참여 링크 → 학생 작성 → 제출 → 교사 전체 글/읽기 안내 → 최소 읽기 확인 → 구체적인 피드백 전달 → 학생 한 대목 다시쓰기·질문 → 교사 후속 확인.

비밀번호를 브라우저 코드·README·저장소에 넣지 마십시오. 실제 비밀값은 플랫폼의 비밀 환경변수에 저장합니다. 운영 시작 시 임시 학급 자료로 한 차례 전체 흐름을 검사하세요.

## 2. 배포

Dockerfile과 compose 예시를 제공합니다. `.env` 파일에 위 환경변수를 설정한 후 `docker compose up --build -d`로 단일 컨테이너를 실행할 수 있습니다. HTTPS 리버스 프록시/인증서/도메인 설정은 호스팅 환경에서 해야 합니다. HTTPS가 없으면 production의 Secure 쿠키가 동작하지 않습니다(로컬 호스트 예외에 의존하지 마세요).

이 저장소에는 외부 운영 배포나 계정/도메인이 연결되어 있지 않습니다. `npm run build` 성공은 실제 서비스 공개와 다릅니다. main 병합/외부 운영 배포는 별도 작업입니다.

서버리스 임시 파일시스템, 자동 다중 레플리카, 클러스터 모드는 지원하지 않습니다. 파일 저장소를 Postgres/객체 저장소로 교체해야 다중 인스턴스로 확장할 수 있습니다.

## 3. 기록 확인

- 학생의 ‘모든 변경사항 저장됨’은 서버 응답 이후에만 표시합니다.
- 서버 저장 실패 시 재시도와 JSON 백업을 제공합니다. 기기 저장 공간 제한도 별도 오류로 알립니다.
- 다른 탭의 수정은 잠금 또는 409로 막고 자동 덮어쓰지 않습니다.
- 제출 후에는 학생 문서가 잠깁니다. 피드백에 답하는 한 대목 연습은 별도로 저장합니다. 전체 글 재제출/교사 되돌려주기는 없습니다.
- 표·링크·이미지를 포함한 본문 리플레이는 ProseMirror steps로 재구성합니다.
- 타임라인의 ‘긴 정지는 2초로 줄이기’는 재생 편의 설정이며 원래 시각을 바꾸지 않습니다.

## 4. 학생 정보와 보관

별명을 사용하고 실제 학생 자료를 넣기 전에 학교의 안내·동의·보관 기간·삭제 요청 창구를 정해야 합니다. 현재 Pilot은 7일 쿠키 기반이며 기관 SSO/다중 교사/계정 복구가 없습니다. 같은 비밀번호를 아는 교사는 모든 과제를 볼 수 있습니다.

학생 이름, 본문, 이전 버전/삭제된 글, 선택 대목, 성찰, 교사 피드백, 최신 후속 응답, 관찰 이벤트와 선택적 시간 파생값이 서버에 저장됩니다. 로컬 IndexedDB는 미제출 복구본을 저장하며 제출 성공 시 해당 복구본을 지웁니다. 공용 기기에서는 과제 종료 후 브라우저 사이트 데이터를 지우세요. 피드백과 후속 응답은 재방문/새로고침으로 확인합니다. 후속 응답은 버튼 저장이며 원문 편집기의 자동 복구 범위에 포함되지 않습니다.

## 5. 백업·삭제

교사 화면은 개별 기록 JSON 다운로드를 제공합니다. 운영자는 서버를 잠시 정지하고 `PROOFWRITE_DATA_DIR` 전체를 암호화된 저장소에 백업하세요. 복구는 같은 경로에 파일을 복원하고 서버를 재시작한 후 문서 재생/권한을 확인합니다. 서버 데이터 파일에만 의존하며 자동 원격 백업은 아직 없습니다.

과제 종료 후 기관의 보관 기간에 따라 운영자가 해당 `submissions/<id>.json`과 관련 `assignments/<id>.json`을 삭제합니다. 온라인 삭제 UI, 학생 주도 삭제 요청 처리와 자동 보관 만료는 미구현입니다. 파일을 삭제하는 동안 서버를 정지하여 동시 쓰기를 막으세요. 내보낸 파일과 백업 사본에도 동일한 보관 정책을 적용하세요.

## 6. 실제 Pilot에서 남은 확인

Windows 한글 IME, macOS, Chromebook, iPad/Safari, 음성 입력/스크린리더/보조기기, 여러 학생 동시 작성, 브라우저 강제 종료, 실제 네트워크 단절, 이미지가 많은 장문 보고서, 학교 방화벽, 개인정보 동의 적합성을 확인해야 합니다. 자동화된 composition 이벤트 시험은 실제 OS 한글 키보드 시험을 대체하지 않습니다.
